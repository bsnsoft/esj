esj package repositories

The apt repository (here) and the dnf repository (under rpm/) of esj, the command line tool of EN16931 Semantic JSON: the native executable for Linux on x86_64 and arm64, with glibc 2.34 or newer. Every version goes to the suite stable, a release candidate as 1.2.3~rc.1, which sorts before 1.2.3.

Debian and Ubuntu (apt)

sudo apt-get update && sudo apt-get install ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.bsnsoft.de/bsnsoft-esj.gpg | sudo tee /etc/apt/keyrings/bsnsoft-esj.gpg > /dev/null
echo 'deb [signed-by=/etc/apt/keyrings/bsnsoft-esj.gpg] https://apt.bsnsoft.de stable main' | sudo tee /etc/apt/sources.list.d/esj.list
sudo apt-get update && sudo apt-get install esj

Fedora and RHEL-family (dnf)

sudo curl -fsSL -o /etc/yum.repos.d/esj.repo https://apt.bsnsoft.de/rpm/esj.repo
sudo dnf install esj

The indices and the rpm packages are signed with the key of BSNSoft Solutions GmbH, fingerprint 39BA1E760ADE6940558B6EEC25FD2A2F5B520EB8 (armoured), the key the libraries on Maven Central are signed with. dnf shows it before it imports it.

Release candidates, upgrades, the packages as downloads and how to check them: docs/install.md. Every release with its archives and packages: github.com/bsnsoft/esj/releases.
